# iPhone 开启开发者模式

1. 用数据线将 iPhone 连接到 Mac
2. 在 iPhone 上进入 **设置 → 隐私与安全性 → 开发者模式**，打开开关
3. 手机会提示重启，重启后信任此电脑（手机上弹出"信任此电脑"时点击"信任"）

# 在 Xcode 中配置签名

iOS 真机测试必须有签名证书，即使是个人免费账号也可以，但需要用 Xcode 配置一次。

1. 打开 Mac 的终端，进入你的 Flutter 项目目录，输入以下命令打开 Xcode 工程：

   ```shell
   open ios/Runner.xcworkspace
   ```

   （注意：一定要打开 `.xcworkspace` 而不是 `.xcodeproj`；退出模拟器，选择你的手机）

2. 在 Xcode 打开后，左侧文件导航栏中点击最顶部的 **Runner** 项目。
3. 在中间区域选择 **Signing & Capabilities** 标签页。
4. 在 **Team** 下拉菜单中：

   - 如果之前没添加过，点击 **Add an Account...**
   - 登录你的 Apple ID（不需要付费开发者账号，普通的就行）
   - 登录后，在 Team 下拉列表中选择你的账号（通常显示为你的名字 - Personal Team）

5. 修改 Bundle Identifier：

   - 在 Team 下方有一个 **Bundle Identifier** 输入框
   - 将它的值改成一个唯一的字符串（例如：`com.你的名字.你的app名字`）。如果不改，可能会提示标识符被占用
   - 修改完成后，确保下方没有红色的报错信息。然后可以直接按 `Cmd + S` 保存，关闭 Xcode（也可以不关，但关了再回到终端操作更方便）

# 在手机上信任开发者证书

因为你使用的是免费的个人 Apple ID，苹果默认不允许运行未上架的 App，所以需要在手机上手动信任。

1. 打开 iPhone 的 **设置 → 通用 → VPN 与设备管理**。
2. 在列表中找到你的 Apple ID（显示为"开发者 App"或你的邮箱名字）。
3. 点击它，然后点击 **"信任 [你的 Apple ID]"**。

# 使用 Flutter 运行 App

1. 回到 Mac 的终端，进入你的项目目录。
2. 输入以下命令查看已连接的设备：

   ```shell
   flutter devices
   ```

   你应该能在列表中看到你的 iPhone 手机（前面带有一个苹果图标）。

3. 直接运行项目：

   ```shell
   flutter run
   ```

   如果有多个设备同时连接，终端会提示你选择设备，输入手机对应的数字回车即可。

# 免费账号的真机测试限制

使用免费的个人 Apple ID 进行真机测试，有几个非常重要的限制你需要知道：

- **7 天有效期限制**：通过免费账号安装的 App，证书只有 7 天的有效期。7 天后 App 会闪退无法打开，你需要重新用数据线连上 Mac，再跑一次 `flutter run` 即可续期。
- **不能直接打包发给别人**：你无法生成 `.ipa` 文件发给其他 iPhone 安装，只能安装在你自己这台已经信任了电脑的设备上。
- **上架 App Store**：如果你想上架，或者想长期使用、分发给内部测试人员，还是需要花 99 美元/年购买 Apple Developer Program 的账号。
